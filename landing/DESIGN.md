# ProjectsFlow — лендинг · дизайн-гайдлайн

**Направление: Hallmark · Wayfind** (с 2026-10-27). Вывеска и табло вокзала: холодная серая
бумага, сине-чёрные чернила, один моноширинный шрифт, квадратные края, рамки 2px, чернильные
таблички. Это зафиксированная система лендинга и блога: каждая страница делит её, а не
придумывает свою. Меняем осознанно; файл — правило.

Приложение остаётся на «C4 плотный» (`docs/superpowers/specs/2026-10-10-redesign-c4-design.md`).
На лендинге C4 — это **материал продукта**: живая доска в hero и окна приложения во вкладках
показаны в настоящем виде приложения, внутри рамки Wayfind. Прежнее направление C4 для самой
страницы и «Dev-cool» сняты.

## Система
- Жанр: modern-minimal. Форма главной: Marquee Hero, hero Banner, навигация — мастхед, подвал —
  «конец письма». Тема: Wayfind (раздача 2/3), цвет: posture committed.
- Подпись страницы: живая доска под вывеской «Это живая доска». Её трогают руками.
- Штамп решений, отказы с причинами и записи редизайна — первые строки `src/styles/globals.css`.

## Токены
`src/styles/hallmark/tokens.css` — источник правды страницы, `hallmark/base.css` — база.
`src/styles/tokens.css` — токены C4; совпадающие по имени (шкала текста, трекинг, кривые, тень
карточки) объявлены только внутри `.pf-product`.

| Роль | Светлая (platform) | Тёмная (night) |
|---|---|---|
| Бумага / вторая / поле | `oklch(95.5% 0.006 250)` / `91%` / `99.5%` | `15%` / `19%` / `20.5%` |
| Чернила / вторые / приглушённый | `oklch(16% 0.014 262)` / `29%` / `45%` | `96%` / `86%` / `73%` |
| Линия / линия на чернилах | `oklch(80% 0.011 250)` / `34%` | `31%` / `40%` |
| Живое (кнопка, фокус, ссылка при наведении) | синий бренда `oklch(52.5% 0.16 252.7)` | барвинок приложения `oklch(68% 0.169 275)` |
| Цифры на чернилах | янтарь `oklch(81% 0.16 82)` — только цифры и только на чернилах | тот же |
| Квадраты линий | цвета статусов приложения: черновик, AI делает, на утверждении, вручную, готово | |

- Шрифт: Martian Mono Variable (`@fontsource-variable/martian-mono`, есть кириллица). Заголовки
  800 со сжатой шириной `font-stretch: 75%`, трекинг −0.03em, высота строки 0.96–1.1; текст 400
  и 500, `tabular-nums` везде. Три насыщенности: 400, 500, 800. Без капса и разрядки.
- Шкала — шаги Hallmark: `--text-section` у h2 (~52px на 1440), `--text-title` у h3, h1 не выше
  4.75rem. Отступы — только `--space-*`. Контейнер 1440px, поля 64 → 24 → 16px.
- Радиус 0 везде, кроме пилюль. Глубина — рамки; теней у карточек нет.

## Компоненты
- Кнопки: главная — заливка синего бренда, вторичная — прозрачная с рамкой 2px; обе квадратные,
  800, 48–52px. Цвет меняется рывком (`steps(1)`), как табло. Без стрелок в тексте.
- Табло (путь задачи, тарифы, вопросы, статьи на главной): шапка столбцов над линией 2px,
  строки через тонкую линию. Чернильная полоса — не больше двух на странице.
- Таблички: квадратное поле в рамке 2px с одним обещанием (гарантии) или одной инструкцией.
- Вкладки: квадратные клетки на общих рамках; выбранная — чернилами. Без JS видны все панели.
- Окна приложения — в `data-slot` с `data-kind="product"`: настоящий скриншот подменит образец
  через `window.hallmarkSlots({...})`.

## Движение
Сурово: смена цвета рывком, без появления секций, без анимации высоты. Сдвиг/поворот — только
под `prefers-reduced-motion: no-preference`; при reduce авто-демо доски выключено.

## Текст
Без тире в тексте страницы (запятая, двоеточие, точка) и без схемы «X — Y» в заголовках. Один
факт — один раз на странице. Цифры в окнах приложения — примеры, это сказано под вкладками.

## Не делаем
Градиенты, свечения, сетки-подложки, скругление карточек, мягкие тени у карточек, третий яркий
цвет, янтарь текстом на бумаге, пропорциональный шрифт на странице, надписи капсом над
заголовками, мета-строки «A · B · C», эмодзи-иконки.

## Exports
`src/styles/hallmark/tokens.css` в этом проекте; Tailwind-маппинг (`tailwind.config.mjs`) по-прежнему
указывает на токены C4 — утилиты на лендинге почти не используются.
