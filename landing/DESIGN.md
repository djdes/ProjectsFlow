# ProjectsFlow — главная · дизайн-гайдлайн

**Направление: чёрная главная** (с 2026-11-25, макет v3 утверждён владельцем в Claude Design,
спека `docs/superpowers/specs/2026-11-25-landing-black-redesign-design.md`; v4 ближе к fluidvoice —
`docs/superpowers/specs/2026-11-25-landing-v4-fluid-design.md`). Приёмы взяты у тёмной
версии fluidvoice.com: двухцветные заголовки, белые кнопки-пилюли, крутящаяся цветная обводка у
пилюли-анонса, текст проступает из размытия при прокрутке. Тексты, картинки и бренд fluidvoice
не используем. Файл — правило: меняем осознанно.

Журнал (`/blog`) эта система не трогает: он свёрстан классами Tailwind на `BaseLayout` и живёт
на своём тёмном фоне. Приложение — «C4 плотный» (`docs/superpowers/specs/2026-10-10-redesign-c4-design.md`).

## Где что
- Страница — `src/pages/index.astro`, блоки — `src/components/home/*` (статичный Astro, без React).
- Стили — `src/styles/home.css`, движение — `src/scripts/home-motion.ts`.
- Тексты — `src/data/home.ts`, тарифы — `src/data/pricing.ts`, вопросы — `src/data/faq.ts`. Из них
  же собираются JSON-LD, `/index.md`, `/llms-full.txt`: правим данные, а не разметку.
- Смоук — `npm run build:landing && npm run test:landing` (`e2e/landing/run.mjs`).

## Токены
Объявлены на `.pf` (не на `:root`: у `tokens.css` блога свои `--font-sans`, `--ease-out`).
Цвета — тройки OKLCH, в коде `oklch(var(--x) / a)`.

| Роль | Значение |
|---|---|
| Фон | `--bg` чистый чёрный; карточки `--bg-1` 11.5%, `--bg-2` 15%, `--bg-3` 19% |
| Текст | `--fg` `97.2% 0.002 250`; второстепенный — белый 56%; вторая половина заголовка (`.dim`) — белый 42% |
| Акценты мелочей | голубой `--cyan`, фиолетовый `--violet`, розовый `--pink` — обводка, свечения, иконки |
| Статусы на доске | `--amber` (на утверждении), `--green` (готово), голубой (AI делает) |
| Логотип | синий бренда `#2383E2` |

- Шрифт: Inter Variable с оптическим размером (`@fontsource-variable/inter/opsz.css`), заголовки
  500, трекинг −0.025em; мелкие метки — JetBrains Mono Variable. Без CDN.
- Размеры: h1 `clamp(40px, 6vw, 84px)`, h2 `clamp(32px, 3.8vw, 54px)`, текст 16–19px.
- Контейнер 1240px, поля `clamp(16px, 4vw, 56px)`. Радиусы: пилюли 999px, карточки 20–24px.

## Компоненты
- Кнопки — пилюли с круглой стрелкой (как у fluidvoice): белая с чёрным кругом и обводка с тёмным
  кругом (`.btn__ic`); при наведении стрелка сдвигается на 2px (только без reduce). В шапке «Войти» —
  обводка, «Начать бесплатно» — белая без круга.
- Первый экран: ПК — слева пилюля-анонс, заголовок, подзаголовок, кнопки и две строки примечания со
  ссылкой «Где ещё»; справа окно доски (две колонки и LIVE-лента) на зернистом белом свечении
  (`.hero__glow`); внизу экрана полоса из четырёх фактов (`.stats`) с разделителями и бирюзовым
  зерном. Уже 1024px — столбиком, на телефоне факты 2×2. На 1024–1279px в окне только доска (LIVE-лента
  не помещается рядом), уже 360px — доска плотнее, без счётчиков колонок. Заголовок — не больше трёх
  строк (до 64px). В окнах ноутбуков (от 1280×730) полоса фактов видна сразу: отступы, высота окна
  доски и размер заголовка следуют за высотой окна, в низком окне в LIVE-ленте четыре события.
- Пилюля-анонс: `.edge` — `conic-gradient` голубой → фиолетовый → розовый, угол
  `@property --edge-a` крутится 6 с, под ним размытая копия-свечение.
- «Где работает» (`#platforms`): веер из пяти карточек (иконка, название, подпись, крупная иконка на
  верхней). ПК — веер с осью далеко под картами; телефон — та же колода лесенкой вниз.
- Тарифы — одна карточка на три колонки с разделителями и радужной линией сверху: название капсом
  и бейдж, крупная цена, слоган, пункты через линии, кнопка внизу (у всех на одной высоте).
- Зерно — статичная SVG-текстура (`--grain`, feTurbulence), без анимации.
- Шапка фиксированная, фон 94% чёрного. До 900px — две строки: логотип и белая кнопка, под ними
  пять разделов (строка листается сама). До 360px кнопка вошедшего — «Открыть», шире — «Открыть
  приложение» (пробел — `&nbsp;`: обычный в начале элемента флекс-строки схлопывается).
- Вход: сервер ставит `html[data-auth="authed"]`; кнопки гостя — `data-auth-anon`, вошедшего
  («Открыть приложение») — `data-auth-authed`: шапка, первый экран, шаги, тарифы, финал, подвал.
- Вопросы — `<details name="faq">`: работают без JS, открыт первый.

## Движение
Двигается текст и несколько сцен, а не каждый блок.

- **Слова из размытия.** Заголовки размечены по словам при сборке (`Words.astro`, `.w` с `--i`).
  Когда заголовок (`.rw`) въезжает в экран, IntersectionObserver ставит `.is-in`, и слова по
  очереди выходят из размытия 10px. Подписи, карточки, шаги, тарифы, вопросы (`.rb`) проявляются
  целиком с небольшой очерёдностью (`--d`). Это переходы CSS, без покадровой работы. Блок, на
  который попал фокус с клавиатуры, проявляется сразу (`focusin`), даже ниже линии проявления.
- Интро первого экрана: слова заголовка, затем пилюля, подзаголовок, кнопки, окно доски — из
  размытия (`softIn`).
- Сцены прокрутки (скрипт пишет переменные, CSS делает `transform`/`opacity`): первый экран
  отъезжает и гаснет под листом с главной фразой (`--h`); слова фразы загораются из размытия по
  одному (класс `.on`); шаги ложатся стопкой (`--c`); «Мелочи» закреплены и едут вбок (`--x`,
  `--pp`); подвал выезжает из-под страницы (`--r`); веер платформ раскрывается при въезде.
- Петля на доске (карточка переезжает на утверждение, LIVE-лента).

Скрытое для проявления и сцены прокрутки — только под `.pf--motion` (его ставит скрипт). Без JS
и при `prefers-reduced-motion: reduce` (класс `.pf--static`) страница статична, весь текст виден,
веер раскрыт, «Мелочи» — обычная горизонтальная прокрутка (с клавиатуры тоже); короткие
анимации — только под `prefers-reduced-motion: no-preference`.

**Печать и PDF.** Скрытые до проявления состояния заданы только для `@media screen`; блок
`@media print` в конце `home.css` ставит сцены прокрутки и закреплённые блоки на свои места,
переносит «Мелочи» строками и останавливает анимации. Шапка печатается один раз.

**Низкие окна** (ноутбук 1366×768, iPhone SE, телефон боком). Первый экран растёт под свой текст;
если он выше окна, то сначала прокручивается до низа и только потом встаёт (`--hero-top`).
Подвал выше окна идёт вместе со страницей (до 900px ширины, до 760px высоты, `.pf--foot-flow`).
Ниже 560px высоты «Мелочи» не закрепляются. Высоты считаются от `100svh`, поэтому свёрнутая
панель Safari страницу не двигает.

**Якоря.** Плавная прокрутка (`.pf-smooth`) включается после загрузки: открывая `/#раздел`,
браузер прыгает сразу, а скрипт после шрифтов и замеров ещё раз ставит раздел под шапку, пока
человек сам не начал листать. Ссылки журнала на разделы главной проверяет смоук.

**Исключения из правил движения CLAUDE.md** (они писались для интерфейса приложения):
интро и проявление длиннее 300 мс и с размытием до 10px; бесконечная анимация угла обводки у
пилюли (маленькая область — это и есть эффект). При reduce выключено всё.

## Текст
Русский, на «ты», без тире в тексте страницы (запятая, двоеточие, точка). Один факт — один раз.
Доска в окне — пример проекта, это сказано подписью под окном. Отзывов нет и не выдумываем: на
их месте гарантии.

## Не делаем
React и новые зависимости ради анимаций (React из лендинга убран целиком); появление с подпрыгиванием и сдвигом больше 16px; `backdrop-filter`
над прокруткой; бесконечные анимации `box-shadow`/`filter`; цвета палитры Tailwind; шрифты с CDN.
