# Подтверждение комментариев

У чужого комментария в «Обсуждении» и в LIVE есть кнопка «Принять». После нажатия она
показывает «Принято», а под сообщением видны имена принявших его людей (почта, если
имя не заполнено). Повторное нажатие снимает только собственную отметку.

Это явное подтверждение сообщения. Открытие задачи само по себе ничего не принимает.
Подтверждение не создаёт комментарий, не запускает воркера и не утверждает задачу.
Адресованный человеку комментарий после подтверждения больше не требует ответа в
фильтре «Ответить». Остальные непринятые вопросы в той же задаче остаются в фильтре;
обычный текстовый ответ, как прежде, закрывает предыдущие вопросы в задаче.

Отметка относится к тексту комментария. Изменение текста сбрасывает её, даже если
правки произошли в одну секунду. Перечитывание списка и realtime обновляют отметки
в других открытых вкладках; автор видит, кто принял сообщение.

Сервер проверяет доступ к конкретной задаче и принадлежность комментария задаче.
Для подтверждения достаточно права чтения, в том числе у назначенного исполнителя
личной задачи без членства в приватном проекте. Идентификатор подтверждающего берётся
только из сессии; подтвердить или отменить отметку от имени другого человека нельзя.

Миграция: `db/171_comment_acknowledgements.sql`.
API: `PUT` / `DELETE /api/projects/:projectId/tasks/:taskId/comments/:commentId/acknowledgement`.
Список комментариев возвращает `acknowledgements` с именами и временем подтверждения.

Проверки: `routes.acknowledgement.test.ts`, `CommentAcknowledgement.behavior.test.ts`,
`HttpTaskRepository.acknowledgement.test.ts`. SQL-контракт
`commentAcknowledgements.integration.test.ts` включается через `PF_COMMENT_ACK_DB=1`:
он использует только временные таблицы одного соединения, не читает и не меняет
пользовательские записи. Локальный запуск из корня:
`node --env-file=.env --import tsx --test server/src/infrastructure/repositories/commentAcknowledgements.integration.test.ts`.
