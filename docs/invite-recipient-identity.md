# Принятие приглашений на почту

Адресное приглашение (с заполненной почтой) принимает только аккаунт с этой почтой.
Сервер читает актуальную почту пользователя из репозитория по ID сессии; значения
из тела запроса не участвуют в проверке. Сравнение игнорирует регистр и окружающие
пробелы. При несовпадении ответ — `403 invite_email_mismatch`, приглашение и состав
участников не изменяются. Правило действует для workspace- и старых project-токенов.

На странице видны текущая почта и адрес приглашения. При несовпадении вместо
принятия доступна кнопка «Сменить аккаунт»; вход или регистрация сохраняют ссылку
приглашения и подставляют нужную почту. Приглашения без адреса остаются ссылками
для любого вошедшего пользователя.

Это уточняет прежнее решение разрешать несовпадение почты из спецификаций
2026-05-19 и 2026-07-13: оно приводило к расходованию приглашения аккаунтом,
случайно открытым на телефоне. Существующие роли и принятые приглашения массово
не пересматриваются; восстановление ошибочно использованной ссылки выполняется
отдельно после проверки конкретного случая.
