# Главная v4: ближе к fluidvoice.com, слова из размытия, хвосты ревью

Дата: 2026-11-25. Статус: владелец выбрал вариант A («Вариант А и сразу в прод»): без отдельного
утверждения макета, сразу в прод после проверок. Основа — главная v3
(`2026-11-25-landing-black-redesign-design.md`, `landing/DESIGN.md`).

## Зачем

Владелец прислал три скриншота fluidvoice.com (первый экран, веер карточек платформ, тарифы) и
просит «больше дизайна из референса»: при прокрутке слова проступают из размытия. Заодно закрыть
всё, что ревью v3 отложило, и убрать мёртвый код старого лендинга.

## Цели

- **Первый экран как у fluid (вариант A).** ПК: слева пилюля-анонс, заголовок, подзаголовок,
  кнопки, две строки примечания со ссылкой «Где ещё работает»; справа окно доски на зернистом
  белом свечении. Внизу экрана — полоса из четырёх фактов (FACTS) с вертикальными разделителями
  и бирюзовым зернистым градиентом. Телефон: то же столбиком (текст, окно, факты 2×2).
  Наезжание сохраняется: первый экран закреплён, лист с главной фразой наезжает на него.
- **Слова из размытия.** Заголовки разделов (и заголовок первого экрана при загрузке) появляются
  по словам: каждое слово из размытия 10px и прозрачности, со сдвигом по очереди. Абзацы, пункты,
  карточки — целиком из размытия, когда въезжают в экран. Слова главной фразы загораются по
  прокрутке и тоже выходят из размытия.
- **Кнопки-пилюли с круглой стрелкой:** белая с чёрным кругом, обводка с тёмным кругом.
- **Веер карточек платформ** — новый раздел «Где работает» (`#platforms`) после «Мелочей»: пять
  карточек (Браузер, iPhone, Telegram, Claude Code, GitHub) веером, раскрываются при въезде в экран;
  у каждой иконка, название и короткая подпись. Бегущая строка платформ из «Мелочей» уходит.
- **Тарифы одной карточкой**: три колонки с разделителями, радужная линия по верхнему краю, над
  ценой — название тарифа капсом, список через линии, кнопка внизу. Крутящаяся обводка «Прайма»
  уходит (у пилюли-анонса остаётся).
- **Хвосты ревью v3:** рамка фокуса не меняет форму пилюль; фраза и шаги не завязаны на число
  слов/шагов; ничего не перерисовывается каждый кадр ради слов; без движения нет анимации наведения;
  кнопки тарифов для вошедшего — «Открыть приложение»; последняя карточка «Мелочей» не встаёт
  вплотную к краю; без движения нет пустой полоски прогресса, лента «Мелочей» листается с
  клавиатуры и видна её полоса прокрутки; у нарисованной кнопки нет курсора-руки; запасной путь
  проявления текста без вечных слоёв.
- **Чистка:** удалить мёртвые компоненты старого лендинга, `hallmark/`, `landing.css`, `board.css`,
  `features.ts`, `nav.ts`, `liquid.ts`, интеграцию React и неиспользуемые зависимости.

## Не цели

- Журнал (`/blog`) визуально не меняется. Тексты главной не переписываем (кроме подписей веера и
  второй строки примечания первого экрана).
- Не копируем тексты, картинки и бренд fluid.

## Против целей

- Не прятать текст без JS и при reduced motion: всё скрытое для проявления — только под
  `.pf--motion` и `prefers-reduced-motion: no-preference`.
- Не вешать покадровую работу на прокрутку ради слов: проявление — переходы (transition) по классу,
  который ставит IntersectionObserver / пересечение порога.
- Не ломать то, что починили в #107: низкие окна, подвал, якоря, iOS-панель.

## Подходы

1. **Проявление по прокрутке (как в v3, `animation-timeline: view()`)** для каждого слова с
   разными диапазонами. Минус: в Firefox/Safari нужен покадровый JS; слова «застывают»
   полупрозрачными, если остановиться.
2. **Появление по въезду в экран (выбран).** IntersectionObserver ставит `.is-in`, слова и блоки
   доезжают переходом с задержкой по индексу (`--i`). Так делает fluid; работает везде, без
   покадровой работы; один раз и до конца.
3. **Библиотека анимаций (framer-motion/GSAP).** Против: новые зависимости и гидрация.

## Решения (мои)

- Слова размечаются при сборке (Astro-компонент `Words.astro`: части с `dim`), не JS-разбиением.
- Окно на первом экране — две колонки доски (AI делает, На утверждении) и LIVE-лента.
- Подписи веера: Браузер — «любой компьютер», iPhone — «как приложение», Telegram — «сводки и
  ответы», Claude Code — «через MCP», GitHub — «коммиты у задач».
- Зерно — статичная SVG-текстура (feTurbulence) data-URI, без анимации.
- Смоук главной расширяется под всё новое (первый экран, полоса фактов, слова, веер, тарифы,
  мелочи, отсутствие React-бандла).
