# Редизайн «C4 плотный»: единая дизайн-система платформы, авторизации и лендинга

Дата: 2026-10-10. Основа — макет C4 со страницы «Входящие» (светлая тема в духе Notion,
плотная раскладка), тёмная тема — макет C3. Весь сайт — приложение, вход/регистрация и
лендинг — должен ощущаться одним продуктом.

## Принципы

1. **Белый лист и серые колонки.** Светлая тема: фон `#FFFFFF`, сайдбар и колонки `#F7F7F5`,
   карточки белые, держатся тенью-кольцом (`shadow-card`), а не рамкой. Тёмная: фон `#16171B`,
   сайдбар `#1A1B20`, колонка `#1D1E23`, карточка `#24262C`, меню и плашки `#2B2D35`,
   линия `#2E3038`; карточка держится рамкой (`shadow-card` в тёмной = кольцо цвета линии).
2. **Цвет = смысл статуса**, одинаковый везде: на утверждении — фиолетовый (`approval`),
   вручную — янтарный (`manual`), очередь — синий акцент (`primary`), готово/принять —
   зелёный (`done`), срок вышел — красный (`destructive`), срок сегодня — `today`.
   Контейнеры нейтральные: цвет живёт в точке, метке, счётчике и зоне броска. Никаких
   цветных заливок целых блоков и полос-рамок слева.
3. **Плотность.** Карточка: радиус 8px, отступы 7×10px, заголовок 13.5px (`text-task`),
   подпись 12.5px (`text-meta`). Колонка: радиус 10px (`rounded-xl`), отступ 6px, зазор 5px.
   Кнопка 32px на десктопе, 44px на тач-экранах. Шапка страницы — строка 44px (`h-11`) с линией
   снизу, заголовок страницы 22px жирный (`text-h1 font-bold`).
4. **Один акцент.** Светлая: синий Notion на полтона темнее — `#0F77D4` (белая подпись на кнопке
   проходит AA), текст-ссылка `#1B6CBD` — `text-primary-ink`.
   Тёмная: барвинок `#7C8CFF` с тёмным текстом на заливке.
5. **Шрифт** — системный стек Notion (Segoe UI / SF), без веб-шрифтов. Полужирный (600) — только
   заголовки, главное действие и заголовок карточки-с-заголовком; остальное 400–500.
6. **Движение** — только функциональное: подсветка зоны броска, «принято», тост отмены.
   Сдвиг/масштаб — под `motion-safe:`.

### Тона-метки (проекты, люди)

Палитра Notion: gray, brown, orange, yellow, green, blue, purple, pink, red. Класс
`pf-tone-<имя>` (выдаёт `lib/tone.ts`: `toneOf(id)`, `projectToneClass(id, isInbox)`) задаёт
`bg-tone-bg`, `text-tone-fg`, `bg-tone` (точка), `bg-tone-solid`/`text-tone-on-solid` (аватар).
Метка — `pf-tag` (`pf-tag-lg` в шапке колонки): в светлой теме пастельная подложка, в тёмной —
текст с цветной точкой без подложки. Статусные метки — те же классы с тонами
`pf-tone-approval`, `pf-tone-manual`, `pf-tone-done`, `pf-tone-queue`.

## Компоненты

- **Кнопки** (`components/ui/button`): `default` — синяя заливка, полужирный; `outline` —
  рамка `border-input`, прозрачная; `ghost` — подложка `bg-hover` по наведению; `accept` —
  мягкий зелёный «Принять/Готово»; `destructive` — красная заливка. Высоты: 32/28/36px.
- **Поле** — 32px, `bg-field`, фокус — синяя рамка.
- **Переключатель вида** (`SegmentedControl`, `Tabs`) — серая подложка, выбранный сегмент —
  белая плашка с лёгкой тенью (тёмная: `bg-raised`).
- **Чипы-фильтры** — 26px, рамка `border-border`, точка смысла слева, счётчик серым;
  выбранный — `bg-primary-soft border-primary`.
- **Карточка задачи** — `rounded-lg bg-card shadow-card px-2.5 py-[7px]`; быстрые действия —
  плашка `bg-raised` в правом верхнем углу по наведению (на тач-экранах — ряд под текстом).
- **Колонка** — `rounded-xl bg-panel p-1.5 gap-[5px]`, шапка 28px: метка-тон + счётчик +
  «свернуть»; свёрнутая — вертикальная полоска 38px.
- **Шапка страницы** — `PageTopBar` (44px, линия снизу) с крошками слева и действиями справа,
  затем строка заголовка `PageTitle` (22px).
- **Тост отмены** — тёмная плашка снизу по центру, действие «Отменить» цветом `toast-accent`.

## Телефон («Входящие»)

Уже 768px доска «Сейчас + очередь» не помещается, поэтому:

- **Разделы по одному.** Липкий переключатель «Сейчас · N / Очередь · M» (`InboxSectionSwitch`,
  кнопки `data-pf-inbox-section-switch`), выбор запоминается. Пока в «Сейчас» пусто, а раздел не
  выбирали, открывается очередь.
- **Очередь — группы стопкой** (`MobileQueueGroup`): проект/срок/приоритет по текущей
  группировке, шапка группы сворачивает её. Вбок ничего листать не нужно. Сроки стопкой идут
  «На сегодня → Будущее → Без срока» — сверху то, что горит.
- **Шапка компактнее:** заголовок с иконками (лупа раскрывает поиск, фильтры, выделение);
  вкладки «Мои / Для всех» и люди — одной лентой вбок; чипы срока — тоже лентой.
- **Свайп вправо — «дальше по процессу»** (`SwipeToAct`): очередь → в работу, «Вручную» → на
  утверждение или готово, полка приёмки → принять. Под карточкой проступает действие цветом
  статуса. Подсказки пустых полок на телефоне называют свайп, а не перетаскивание.
- **Кнопки карточки 40px** (как в мобильном ряду карточки доски), иконки 16px.
- **Долгий тап — перетаскивание**, внизу появляется док «В работу / Готово» (`MobileDragDock`) —
  скрытый раздел не мешает бросить задачу куда нужно. У исполнителя при включённой приёмке
  вторая цель называется «На утверждение»: «Готово» и так отправляет работу руководителю.
- **Плавающая кнопка «Новая задача»** над нижней навигацией.
- **Панель выделения** (`BulkActionBar`) на телефоне — две строки: «Выбрано N» с крестиком и
  лента действий, которая листается вбок; в шапках групп очереди — «Все / Очистить».

## Телефон (общие правила)

- **Тач-цели 40px** у кнопок-иконок в рядах карточек, окна задачи, композеров (`max-sm:size-10`);
  кнопки без `size-*` и так получают 44px из глобального правила `globals.css`.
- **Меню на телефоне — нижний лист** и открывается по `click`, а не по `pointerdown`
  (`components/ui/dropdown-menu.tsx`): иначе лист появлялся под пальцем и тот же тап выбирал пункт.
- **Наведения нет** — то, что на десктопе проявляется по hover, на сенсорном экране видно всегда
  (`[@media(hover:none)]:opacity-100`), подсказки горячих клавиш прячутся (`[@media(pointer:coarse)]:hidden`).
- **Доска проекта:** над рядом колонок — чипы колонок (`BoardColumnTabs`) с числом задач и
  подсветкой текущей; плашки и строка проекта на телефоне уезжают со страницей, закреплена только
  шапка колонки; «выполнено» в ряду кнопок карточки — у правого края, подальше от её середины.
- **Плашка «Код подключён»** на телефоне — одна строка: подпись, «Запустить», крестик.

## Лендинг

Тот же язык: белый лист и серые секции, текст `#37352F`, акцент `#0F77D4`, статусные цвета как в
приложении, системный шрифт, карточки с тенью-кольцом, тёмная тема по
`prefers-color-scheme` — палитра C3. Терминально-неоновый стиль (циан, сетка, свечения) убран.

## Чего не делаем

- Не заливаем блоки цветом статуса (полка «на утверждении» — нейтральная панель с фиолетовой
  меткой, а не фиолетовый прямоугольник).
- Не добавляем «полосы» слева, эмодзи-декор, градиенты ради украшения.
- Не используем палитру Tailwind (`violet-500`, `emerald-600`…) для смыслов, у которых есть токен.
  Палитра остаётся только для данных без смысла статуса (подсветка синтаксиса, диаграммы).
