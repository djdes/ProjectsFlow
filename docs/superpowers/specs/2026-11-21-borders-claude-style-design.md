# Рамки и тач-зоны в стиле приложения Claude — дизайн

Дата: 2026-11-21. Статус: утверждён владельцем («везде измени всё, утверждаю»).

## Зачем

Интерфейс выглядит «грязно»: рамки разного оттенка и толщины, пунктиры, рамки внутри рамок.
Нужен аккуратный вид мобильного приложения Claude (PWA на iPhone), удобные для пальца кнопки,
приятные светлая и тёмная темы.

## Решения владельца

- **Палитра остаётся** (вариант А): светлая Notion, тёмная графит C3, синий/барвинковый акцент,
  цвета статусов без изменений.
- **Рамки по сайту остаются**, но единые и тонкие.
- **Комментарии, ответы, чат воркера — без рамок**: пузырь держится заливкой, поле ответа —
  залитая капсула.
- Применить везде (весь `client/`). Лендинг и блог — вне объёма.

## Подходы

1. Ручная правка ~1000 классов `border*` в 204 файлах — долго, риск новой несогласованности.
2. **Выбрано:** правка на уровне токенов и примитивов (`--border`, `--input`, `Card`, `Input`,
   `Button outline`, `.pf-*` в CSS) + механическая нормализация случайных оттенков рамок
   (`border-border/60`, `/70`, `foreground/30` …) к одному токену + ручная правка зон
   комментариев/чата.
3. Убрать рамки целиком и держаться на заливке — отклонено владельцем.

## Дизайн

- **Рамка:** одна тонкая линия `--border` на тему (светлая — чуть мягче, тёмная — на ступень
  ближе к фону); `--input` = тот же уровень, фокус — акцент. Оттенки `border-border/NN` и
  `border-foreground/30` → `border-border`. Пунктир остаётся только у зон броска/загрузки.
- **Скругления:** карточки/группы `rounded-xl` на мобиле, как в Claude; список-группы —
  внешняя рамка, разделители внутри.
- **Тёмная тема:** ступени фон → панель → карточка разнесены заметнее, чтобы блоки читались
  при мягкой рамке.
- **Комментарии/чат:** `WorkerChatMessage`, `WorkerResultMessage`, `CommentBody`, ответы,
  `TaskDrawerComposer` (капсула `bg-muted`, без `border-input`), полоса «ответ на…», чипы
  вложений, картинки — без рамок.
- **Тач:** на `max-sm` у мелких интерактивных элементов зона нажатия ≥44px через
  расширение hit-area (псевдоэлемент), без раздувания вёрстки; отклик на `:active`.

## Оставлено исполнителю

Конкретные значения OKLCH, список точечных правок, способ hit-area — по месту, с проверкой
скриншотами 375px в обеих темах и прогоном typecheck/lint/smoke.
