# Главная projectsflow.ru: чёрная версия по мотивам fluidvoice.com

Дата: 2026-11-25. Статус: макет утверждён владельцем («утверждаю, делай вёрстку и в прод»).
Макет: Claude Design, холст «ProjectsFlow — новая главная»
(`https://claude.ai/artifact/WMJjf7EHevwHiFgwNPwXcu`, версия v3).

## Зачем

Владелец хочет новую главную с нуля: чёрную, стильную, с анимациями, чтобы впечатляла и на ПК, и на
телефоне. Ориентир — тёмная версия fluidvoice.com: двухцветные заголовки, белые кнопки-пилюли,
крутящаяся цветная обводка у пилюли-анонса, текст, который проступает из размытия при прокрутке.
Прежняя витрина (фиолетовая, с 3D-ядром, `components/showcase/*`) уходит целиком.

## Цели

- Главная повторяет утверждённый макет v3 на ширине от 320 до 1440+ px.
- Анимации работают в любом современном браузере, включая iPhone; при `prefers-reduced-motion:
  reduce` страница статична и полностью читаема.
- Тексты, тарифы и вопросы берутся из `landing/src/data/*`, разметка schema.org, `/index.md` и
  `/llms-full.txt` собираются из тех же данных.
- Для вошедшего пользователя кнопки «Войти / Начать бесплатно» заменяются на «Открыть приложение»
  (сервер ставит `html[data-auth="authed"]`, см. `server/src/presentation/public/promoDelivery.ts`).

## Не цели

- Блог (`/blog`) не переделываем: он остаётся на своём оформлении и общем `BaseLayout`.
- Не копируем тексты, картинки и бренд fluidvoice: только приёмы (обводка, кнопки, цвета, движение).
- Отзывов нет и выдумывать их нельзя: на их месте гарантии.

## Против целей

- Не тащим React на главную ради анимаций: страница статичная, движение — CSS и небольшой скрипт.
- Не вводим новые зависимости: шрифты уже есть (`@fontsource-variable/inter`, `jetbrains-mono`).

## Подходы

1. **React-остров, как старая витрина.** Плюс: знакомо. Минус: React-рантайм и гидрация ради
   страницы, где нет состояния, кроме аккордеона; хуже первая отрисовка.
2. **Статичный Astro + маленький скрипт (выбран).** Разметка — Astro-компоненты, аккордеон —
   `<details>`, движение — CSS (`animation-timeline: view()` для текста) и один модуль на ~150 строк
   для прокрутки (первый экран, окно доски, стопка шагов, лента, подвал). Быстро, без гидрации,
   работает без JS.
3. **Вставить HTML холста как есть.** Минус: холст держит данные в разметке и логику в формате
   Claude Design; данные разошлись бы с `data/*` и llms.

## Дизайн (как утверждён)

Система лендинга описана в `landing/DESIGN.md` (заменяет Hallmark · Wayfind для главной).

- **Цвета.** Фон чисто чёрный, текст `#f5f6f7`, второстепенный — белый 56%, вторая половина
  заголовков — белый 42%. Акценты для мелочей: голубой `#38bdf8`, фиолетовый `#a78bfa`, розовый
  `#f0abfc` (в коде тройки OKLCH), янтарь и зелёный — статусы на доске. Логотип — синий бренда.
- **Шрифт.** Inter Variable с оптическим размером (`@fontsource-variable/inter/opsz.css`), заголовки
  500, трекинг −0.025em; моноширинный JetBrains Mono для мелких меток.
- **Шапка.** Фиксированная, тёмная полупрозрачная. ПК: логотип | разделы по центру | «Войти» в
  тонкой обводке и белая «Начать бесплатно». Телефон: две строки — логотип и белая кнопка, под ними
  пять разделов.
- **Первый экран.** Закреплён (`position: sticky`). Пилюля-анонс с крутящейся обводкой
  голубой → фиолетовый → розовый (6 с) и свечением; двухцветный заголовок «Опиши идею. / Получи
  готовый продукт.»; подзаголовок; белая кнопка и кнопка-обводка со стрелкой при наведении;
  серебристая дуга горизонта; мягкий свет за курсором (ПК).
- **Окно доски** выезжает из-за дуги, наезжает на первый экран и выпрямляется из наклона; внутри
  петля: карточка переезжает «AI делает → На утверждении», справа LIVE-лента.
- **Главная фраза** листом с закруглённым верхом поверх первого экрана; слова загораются по одному,
  за фразой голубо-фиолетовое свечение; под ней четыре факта.
- **Разделы:** «Больше, чем доска» (LIVE-лента, Автопилот), «Как это работает» (заголовок слева
  стоит, четыре шага ложатся стопкой), «Мелочи» (раздел закреплён, карточки едут вбок при прокрутке
  вниз, строка платформ бежит), тарифы (у «Прайма» медленная цветная обводка), гарантии, вопросы,
  финальный призыв, подвал выезжает из-под страницы.
- **Текст в разделах** (h2, h3, p, пункты тарифов) проступает из размытия, пока въезжает в экран:
  прозрачность 15% → 100%, размытие 4px → 0, сдвиг 18px → 0, привязано к прокрутке
  (`animation-range: entry 0% entry 80%`). Карточки сами не прыгают.

## Исключения из правил движения CLAUDE.md (только лендинг)

Правила CLAUDE.md про движение писались для интерфейса приложения. На главной осознанно:

- интро первого экрана 1–1.2 с с размытием до 10px (по образцу fluidvoice), текст в разделах —
  размытие до 4px;
- эффекты, привязанные к прокрутке, пересчитывает скрипт в `requestAnimationFrame` по событию
  прокрутки (только переменные `transform`/`opacity`); проявление текста — CSS
  `animation-timeline: view()`, скрипт включается только там, где её нет;
- бесконечная анимация угла `conic-gradient` у пилюли и карточки «Прайм» перерисовывает маленькую
  область — это и есть эффект, о котором просил владелец;
- при `prefers-reduced-motion: reduce` всё это выключено.

## Файлы

- `landing/src/pages/index.astro` — новая страница из компонентов `landing/src/components/home/*`.
- `landing/src/components/home/*.astro` — шапка, первый экран с окном доски, фраза, разделы, тарифы,
  вопросы, финал, подвал.
- `landing/src/styles/home.css` — стили главной; `landing/src/scripts/home-motion.ts` — движение.
- `landing/src/data/home.ts` — тексты главной (факты, возможности, шаги, мелочи, гарантии); из него
  же собираются `/index.md` и `/llms-full.txt`.
- `landing/src/data/pricing.ts` — у VIP кнопка «Оставить заявку».
- `landing/src/layouts/BaseLayout.astro` — необязательный `themeColor`.
- Удаляются `landing/src/components/showcase/*` и `landing/src/data/showcaseData.ts`.
- `landing/DESIGN.md`, `CLAUDE.md` — новая система главной.
