# Рамки и тач-зоны в стиле Claude — план

> Исполнение: native (в этой сессии), проверка скриншотами 390px/1440px в обеих темах.

**Goal:** единые тонкие рамки по сайту, комментарии/чат без рамок, зоны нажатия ≥44px на тач.

**Architecture:** правка токенов (`globals.css`) и примитивов (`components/ui`), механическая
нормализация оттенков рамок, ручная правка зон комментариев/чата, глобальное CSS-правило hit-area.

**Spec:** `docs/superpowers/specs/2026-11-21-borders-claude-style-design.md`

## Global Constraints

- Палитра, акцент и цвета статусов не меняются; лендинг/блог не трогаем.
- CSS по good-css: OKLCH-тройки, логические стороны, движение только под `motion-safe`.
- Пользовательские строки — русские; комментарии в коде — как в окружающем файле.

## Review Focus

- Абсолютно позиционированные кнопки не должны терять `absolute` из-за правила hit-area.
- Расширенная зона нажатия не перекрывает соседний элемент сильнее, чем на 12px с каждой стороны.
- Поле комментария без рамки остаётся различимым на белом фоне и в тёмной теме, фокус виден.
- Пузырь своего/чужого сообщения различим без рамки в обеих темах.
- Смоук не находит горизонтальной прокрутки на 320px.
